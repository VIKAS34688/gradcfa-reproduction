# GradCFA Environment

## Current Setup

- Operating system: Windows
- Python version: 3.14.7
- Virtual environment: gradcfa_env
- PyTorch version: 2.14.1+cpu
- GPU: NVIDIA GeForce GTX 1650 (4 GB VRAM)
- NVIDIA driver: 581.83
- Current PyTorch CUDA support: Not available

## Important Notes

The NVIDIA GPU and driver are available, but this environment currently has a CPU-only PyTorch installation. GPU execution requires a compatible CUDA-enabled PyTorch build. The environment has not been verified for every experiment.
