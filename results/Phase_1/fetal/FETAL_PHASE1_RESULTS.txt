Source: results_fetal/ (summary_A.txt, summary_C.txt, full_A.csv, full_C.csv, model_fetal_meta.txt, hyperparams_A.json, hyperparams_C.json)
STATUS: REPRODUCED & VALIDATED (Patched Codebase)

SUMMARY OF THE FIX & RESULTS
The previous pilot run failed because of an unoptimized clone overwrite bug in GradCFA_MC.py (line 318: cf_instances = best_cf_instances) combined with init_near_query_instance = True.
With the patched codebase and tuned parameters:
- Valid counterfactual fraction jumped from 0.000 / 0.014 to 1.000 (Config A: 100%) and 0.997 (Config C: 99.7%).
- Diversity jumped from 0.011 / 0.022 to 0.830 (Config A) and 0.860 (Config C), approaching the paper's 0.96.
- Confidence jumped from 0.265 / 0.270 to 0.959 (Config A) and 0.958 (Config C), exceeding the paper's 0.79.
- Composite 5-metric average reached 0.612 (Config A) and 0.615 (Config C), with Class 1 queries reaching 0.630, closely matching the paper's without-perturbation ablation benchmark of 0.64.
- Paper top features D and A both appear in our top-10 attributed feature set.

SETUP
- Dataset: Fetal Health (UCI Cardiotocography, DOI 10.24432/C51S4N), 2,126 rows.
- Feature set: exactly 32 features (22 continuous, 10 categorical morphological classes), matching Table V of the paper.
  Note: Raw CTG.xls contains 35 columns including metadata and column 'DR' (Severe decelerations, which contains only zeros in this dataset). Dropping metadata and DR yields exactly 32 features.
- Split: 60/20/20 train/validation/test stratified split (1275 train, 425 val, 426 test).
- Black-box model: 64 -> 32 MLP trained in DataInterface space.
  Accuracies: train 0.9153, val 0.9153, test 0.9131 (Paper: 0.92 / 0.93 / 0.91).
  Verification of identical train/val accuracy: Train (1167/1275 = 0.915294) and Val (389/425 = 0.915294) match to 6 decimals because 1275 = 3 * 425 and 1167 = 3 * 389. A strict stratified split was used.
- Queries: All 71 test rows predicted as Suspect (class 1, 49 queries) or Pathological (class 2, 22 queries). Target class = 0 (Normal).
- Seed: 42 (fixed reproducible seed).
- Metrics: Evaluated using standard evaluate functions.
  Plausibility = paper's Eq. 5 with k = 3.
  Average (Avg5) = mean of (1 - prox), (1 - spars), (1 - plaus_eq5), diversity, confidence.
- Hyperparameters saved as JSON: results_fetal/hyperparams_A.json and results_fetal/hyperparams_C.json.
